Botão flutuante sobre outros aplicativos

O Print Fácil web captura a tela com autorização do navegador. Para manter um botão flutuante visível sobre o WhatsApp, a galeria ou qualquer outro app — e capturar a tela do sistema — é obrigatório empacotar a interface em um app Android com uma camada nativa em Kotlin.

Limite real da plataforma web

Nenhuma página HTML, mesmo instalada como PWA, pode desenhar sobre outros apps nem ler o framebuffer do sistema. SYSTEM_ALERT_WINDOW, MediaProjection e serviço em primeiro plano só existem no Android SDK. O app web continua sendo a interface e a galeria; o nativo faz o overlay e a captura.

1. Arquitetura em três camadas

1

WebView / interface

O mesmo HTML/CSS/JS deste projeto roda no WebView. Galeria, ajustes e prévia continuam em IndexedDB.

2

Ponte JavaScript

addJavascriptInterface expõe PrintFacilNative; o WebView recebe eventos via evaluateJavascript.

3

Nativo Kotlin

Serviço em primeiro plano mantém o overlay com TYPE_APPLICATION_OVERLAY e executa o MediaProjection.

app/
├─ MainActivity.kt               // hospeda o WebView + ponte
├─ FloatingButtonService.kt      // overlay arrastável (foreground service)
├─ ScreenCaptureManager.kt       // MediaProjection → Bitmap → PNG/JPG
├─ PrefsStore.kt                 // posição, tamanho, opacidade, formato
└─ assets/  (index.html, css/, js/, icons/, manifest.webmanifest)

2. Permissões e o consentimento em cada versão

PermissãoPara quêComo é concedida
SYSTEM_ALERT_WINDOW Desenhar o botão sobre outros apps Intent ACTION_MANAGE_OVERLAY_PERMISSION → tela de Ajustes do usuário (não é runtime permission)
FOREGROUND_SERVICE Manter o overlay vivo fora do app Declarada no manifest + notificação obrigatória
FOREGROUND_SERVICE_MEDIA_PROJECTION Serviço de projeção (Android 14+) Declarada + foregroundServiceType="mediaProjection"
POST_NOTIFICATIONS Notificação do serviço (Android 13+) Runtime permission via rememberLauncherForActivityResult
MediaProjection Capturar a tela do sistema Diálogo do sistema createScreenCaptureIntent() — sempre por sessão/token
Regra de ouro

Cada captura precisa de um token de MediaProjection válido. No Android 14+ o token é de uso único: reutilizar o VirtualDisplay antigo derruba o app. A solução é manter uma única sessão ativa enquanto o serviço estiver em primeiro plano, criando um novo ImageReader por captura a partir do mesmo display.

4. Serviço em primeiro plano com o botão flutuante

O WindowManager recebe uma View com TYPE_APPLICATION_OVERLAY (Android 8+) ou TYPE_PHONE em versões antigas. O arrasto usa OnTouchListener com FLAG_NOT_FOCUSABLE, e a posição é salva para sobreviver a reinícios. 

class FloatingButtonService : Service() {

    private lateinit var windowManager: WindowManager
    private lateinit var button: ImageView
    private lateinit var params: WindowManager.LayoutParams
    private var capture: ScreenCaptureManager? = null

    override fun onCreate() {
        super.onCreate()
        startForeground(NOTIF_ID, buildNotification())
        windowManager = getSystemService(WINDOW_SERVICE) as WindowManager
        showFloatingButton()
    }

    private fun showFloatingButton() {
        button = ImageView(this).apply {
            setImageResource(SGE(R.drawable.ic_camera))
            background = GradientDrawable().apply {
                shape = GradientDrawable.OVAL
                setColor(Color.parseColor("#5B8CFF"))
            }
            elevation = 12f
        }

        val size = PrefsStore.buttonSize(this)          // 44..96 dp
        params = WindowManager.LayoutParams(
            size, size,
            WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY,
            WindowManager.LayoutParams.FLAG_NOT_FOCUSABLE,
            PixelFormat.TRANSLUCENT
        ).apply {
            gravity = Gravity.TOP or Gravity.START
            x = PrefsStore.x(this@FloatingButtonService)
            y = PrefsStore.y(this@FloatingButtonService)
            alpha = PrefsStore.opacity(this@FloatingButtonService)  // 0.35..1.0
        }

        button.setOnTouchListener(DragTouchListener())
        windowManager.addView(button, params)
    }

    /** Distingue toque de arrasto: só captura se o dedo não se moveu. */
    private inner class DragTouchListener : View.OnTouchListener {
        private var initialX = 0
        private var initialY = 0
        private var touchX = 0f
        private var touchY = 0f
        private var moved = false

        override fun onTouch(v: View, event: MotionEvent): Boolean {
            when (event.action) {
                MotionEvent.ACTION_DOWN -> {
                    initialX = params.x; initialY = params.y
                    touchX = event.rawX; touchY = event.rawY
                    moved = false
                    v.animate().scaleX(0.9f).scaleY(0.9f).setDuration(90).start()
                    return true
                }
                MotionEvent.ACTION_MOVE -> {
                    val dx = (event.rawX - touchX).toInt()
                    val dy = (event.rawY - touchY).toInt()
                    if (abs(dx) > DRAG_SLOP || abs(dy) > DRAG_SLOP) moved = true
                    if (moved) {
                        params.x = initialX + dx
                        params.y = initialY + dy
                        windowManager.updateViewLayout(v, params)
                    }
                    return true
                }
                MotionEvent.ACTION_UP -> {
                    v.animate().scaleX(1f).scaleY(1f).setDuration(120).start()
                    if (moved) {
                        PrefsStore.savePosition(this@FloatingButtonService, params.x, params.y)
                    } else {
                        onCaptureRequested()   // toque simples → captura
                    }
                    return true
                }
            }
            return false
        }
    }

    private fun onCaptureRequested() {
        capture = ScreenCaptureManager(this) { bitmap ->
            // 1) esconde o overlay para ele não sair na imagem
            button.visibility = View.INVISIBLE
            // 2) salva e devolve para a interface web
            val file = saveBitmap(bitmap)          // PNG ou JPG conforme ajuste
            button.visibility = View.VISIBLE
            MainActivity.webView?.post {
                MainActivity.webView?.evaluateJavascript(
                    "window.PrintFacilNative_receive('${file.toURI()}')", null
                )
            }
        }
        capture?.requestCapture(this, button)
    }

    override fun onDestroy() {
        super.onDestroy()
        capture?.release()
        if (::button.isInitialized) windowManager.removeView(button)
    }

    override fun onBind(intent: Intent?): IBinder? = null

    companion object {
        private const val NOTIF_ID = 4201
        private const val DRAG_SLOP = 8
    }
}
Android 12+ e a notificação

Serviços em primeiro plano não podem iniciar a partir do background sem uma exceção válida. Inicie o serviço quando o usuário tocar em “Ativar botão flutuante” no app (contexto de primeiro plano), e nunca a partir de um BOOT_COMPLETED receive sem checar canStartForegroundService.

5. MediaProjection → Bitmap → arquivo

class ScreenCaptureManager(
    private val context: Context,
    private val onBitmap: (Bitmap) -> Unit
) {
    private var projection: MediaProjection? = null
    private var virtualDisplay: VirtualDisplay? = null
    private var imageReader: ImageReader? = null
    private val handler = Handler(Looper.getMainLooper())

    /** Abre o diálogo do sistema uma única vez e mantém a sessão viva. */
    fun requestCapture(activity: Activity, launchUi: ActivityResultLauncher<Intent>) {
        val mgr = context.getSystemService(MEDIA_PROJECTION_SERVICE) as MediaProjectionManager
        launchUi.launch(mgr.createScreenCaptureIntent())
    }

    fun onActivityResult(resultCode: Int, data: Intent, metrics: DisplayMetrics) {
        val mgr = context.getSystemService(MEDIA_PROJECTION_SERVICE) as MediaProjectionManager
        projection = mgr.getMediaProjection(resultCode, data) ?: return

        // Android 14+ exige um callback antes de criar o VirtualDisplay.
        projection?.registerCallback(object : MediaProjection.Callback() {
            override fun onStop() { release() }
        }, handler)

        val w = metrics.widthPixels
        val h = metrics.heightPixels
        imageReader = ImageReader.newInstance(w, h, PixelFormat.RGBA_8888, 2)
        virtualDisplay = projection?.createVirtualDisplay(
            "PrintFacil", w, h, metrics.densityDpi,
            DisplayManager.VIRTUAL_DISPLAY_FLAG_AUTO_MIRROR,
            imageReader?.surface, null, handler
        )

        imageReader?.setOnImageAvailableListener({ reader ->
            val image = reader.acquireLatestImage() ?: return@setOnImageAvailableListener
            image.use {
                val plane = it.planes[0]
                val rowPadding = plane.rowStride - plane.pixelStride * w
                val bitmap = Bitmap.createBitmap(
                    w + rowPadding / plane.pixelStride, h, Bitmap.Config.ARGB_8888
                )
                bitmap.copyPixelsFromBuffer(plane.buffer)
                onBitmap(Bitmap.createBitmap(bitmap, 0, 0, w, h))
            }
        }, handler)
    }

    fun release() {
        virtualDisplay?.release(); virtualDisplay = null
        imageReader?.close(); imageReader = null
        projection?.stop(); projection = null
    }
}

/** Compressão respeitando o ajuste escolhido na interface web. */
fun saveBitmap(bitmap: Bitmap, format: String = "png", quality: Int = 92): File {
    val file = File(context.filesDir, "printfacil-${System.currentTimeMillis()}.${format}")
    file.outputStream().use { out ->
        if (format == "jpg") {
            bitmap.compress(Bitmap.CompressFormat.JPEG, quality, out)
        } else {
            bitmap.compress(Bitmap.CompressFormat.PNG, 100, out)
        }
    }
    return file
}
Privacidade do token

Guarde o data do Intent apenas em memória. Ele concede acesso à tela inteira: não persista em SharedPreferences, não envie por rede e descarte ao parar o serviço.

6. Ponte JavaScript ↔ Kotlin

Exponha somente funções específicas (nunca addJavascriptInterface(Object())). Do lado web, detecte a ponte e use-a quando existir; caso contrário, caia para a Screen Capture API — é exatamente o que js/capture.js faz hoje. 

// MainActivity.kt
webView.settings.apply {
    javaScriptEnabled = true
    domStorageEnabled = true
    allowFileAccess = false
}
webView.addJavascriptInterface(NativeBridge(this), "PrintFacilNative")

class NativeBridge(private val activity: MainActivity) {

    @JavascriptInterface
    fun isAndroidApp(): Boolean = true

    @JavascriptInterface
    fun hasOverlayPermission(): Boolean =
        Settings.canDrawOverlays(activity)

    @JavascriptInterface
    fun requestOverlayPermission() {
        activity.startActivity(
            Intent(Settings.ACTION_MANAGE_OVERLAY_PERMISSION,
                Uri.parse("package:${activity.packageName}"))
        )
    }

    @JavascriptInterface
    fun startFloatingButton() {
        ContextCompat.startForegroundService(
            activity, Intent(activity, FloatingButtonService::class.java)
        )
    }

    @JavascriptInterface
    fun stopFloatingButton() {
        activity.stopService(Intent(activity, FloatingButtonService::class.java))
    }

    @JavascriptInterface
    fun setFabOptions(sizeDp: Int, opacityPercent: Int) {
        PrefsStore.saveButtonStyle(activity, sizeDp, opacityPercent / 100f)
    }
}
// Trecho para js/capture.js em ambiente Android empacotado
function hasNativeBridge() {
  return typeof window.PrintFacilNative !== 'undefined' &&
         window.PrintFacilNative.isAndroidApp();
}

// O nativo devolve o arquivo salvo, que entra na mesma galeria IndexedDB.
window.PrintFacilNative_receive = function (fileUri) {
  fetch(fileUri)                 // file:// exposto pelo app empacotado
    .then(function (r) { return r.blob(); })
    .then(function (blob) {
      return PF.gallery.addAndRefresh({
        blob: blob,
        type: blob.type || 'image/png',
        createdAt: Date.now(),
        source: 'android-overlay'
      });
    })
    .then(function () { PF.app.toast('Captura do overlay salva.', 'ok'); });
};

7. Fluxo do usuário (primeira execução)

  1. Abrir o app

    WebView carrega index.html de assets/; a galeria lê o IndexedDB local.

  2. Permitir sobreposição

    Settings.canDrawOverlays() falso → abre a tela de Ajustes do sistema uma única vez.

  3. Ativar o botão flutuante

    Serviço em primeiro plano sobe com notificação; o overlay aparece na posição salva.

  4. Autorizar captura de tela

    Diálogo do sistema createScreenCaptureIntent(). Aceito uma vez por sessão do serviço.

  5. Capturar em um toque

    Toque no botão → overlay oculto → Bitmap → PNG/JPG → prévia na galeria.

8. Checklist de entrega

  • Overlay arrastável, com posição/tamanho/opacidade persistidos
  • Serviço em primeiro plano com notificação e ação “Parar”
  • Sessão de MediaProjection única, liberada no onDestroy
  • Uma captura por toque, sem espera extra após as permissões
  • Botão oculto durante a captura para não sair na imagem
  • Arquivos em PNG/JPG conforme ajuste, salvos localmente e na galeria
  • Nenhum envio de imagem para servidor; sem telemetria de conteúdo
  • Testado em Android 10, 12, 13 e 14+ (token de uso único)
